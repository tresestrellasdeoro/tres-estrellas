Credenciales Requeridas para Proceder

⚠️  Único pendiente — Acceso AWS del cliente

  • AWS Access Key ID y Secret Access Key (usuario IAM con permisos de lectura)
  • Nombre de la base de datos y región AWS (ej. us-west-2)
  • Endpoint del RDS o servidor de base de datos en AWS
  • Nombre de usuario y contraseña de la base de datos
  • Puerto de conexión (default 3306 MySQL / 5432 PostgreSQL)

Nota de seguridad: Las credenciales serán utilizadas exclusivamente para la lectura y extracción de datos durante el proceso de migración. No se almacenarán ni compartirán con terceros. Se recomienda crear un usuario IAM temporal de solo lectura para este proceso.
